# desarrollo_web_sebastian_cadena

Entre los objetivos que debe cumplir el sistema están:

● [1 punto] registro de miembros de la comunidad, solicitando datos que permitan
identificar y contactar a la persona. Debe considerar los distintos tipos de miembros y, si
corresponde, datos acorde a su función.

● [1,5 puntos] los miembros registrados puedan informar actividades que realizan, junto
con los horarios (días y horas) dedicados a estas actividades y además se debe exigir
agregar al menos un archivo con fotos o videos, además de algún enlace a contenido
propio de las actividades.

● [1 punto] consultar listados de miembros, que permita filtrar por tipo y ordenamiento por
diversos datos (nombre, datos de contacto), presentando la información por páginas.

● [0.5 puntos] consulta de indicadores y métricas (gráficos) sobre miembros registrados y
actividades que realizan.
